# lampa-audio-select

Плагин для [Lampa](https://github.com/yumata/lampa): автоматически включает аудиодорожку на выбранном языке при запуске видео.

## Установка

**Настройки → Расширения → Добавить плагин** и вставьте ссылку:

```
https://evilhag93.github.io/lampa-audio-select/audio-select.js
```

Перезапустите Lampa.

## Настройка

**Настройки → Плеер → Язык аудиодорожки**:

- **Не менять** (по умолчанию): плагин ничего не делает.
- **Русский**, **English** или **Українська**.

Когда дорожка переключена, внизу экрана появится уведомление с её названием.

## Как это работает

- Когда плеер получает список дорожек файла, плагин ищет подходящую:
  1. сначала по коду языка дорожки (`ru`/`rus`, `en`/`eng`, `uk`/`ukr`);
  2. если коды не проставлены, по названию дорожки (`English`, `Русский`, `Укр` и т.п.).
- Если подходящих дорожек несколько, берётся первая. Если нет ни одной, ничего не меняется.
- Для каждого файла выбор делается один раз при запуске. Если переключить дорожку вручную, плагин её не перебьёт.
- Онлайн-источники с собственным выбором озвучки и транскодирование TorrServer (`/gst/`) плагин не трогает.

## Ограничения

- Работает только со встроенными дорожками видеофайла. Внешние дорожки (отдельные `.mka` в раздаче) не переключает.
- Работает только во встроенном плеере Lampa, во внешних плеерах не действует.
